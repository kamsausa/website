# KAMSA website

A responsive one-page redesign for the Korean American Medical Student Association.

## Preview

Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Editing

- Main page content: `index.html`
- Colors, layout, and responsive design: `styles.css`
- Mobile navigation, scroll effects, and counters: `script.js`
- Official KAMSA logo: `assets/kamsa-logo.jpg`
- Homepage cover photograph: `assets/cover-image.jpg`
- Partner logos: `assets/partner-kama.jpeg`, `assets/partner-national-ksa.jpeg`, and `assets/partner-liner.jpeg`

The three K-MEDS carousel entries are sample editorial copy. Replace their titles, descriptions, and links in `index.html` with the official episode details. The Instagram, Discord, and Kakao cards currently route visitors to KAMSA's contact page until the official public or invitation links are added.

The site has no third-party runtime dependencies and can be deployed to any static host.
